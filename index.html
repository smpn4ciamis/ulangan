Pengaturan Guru - Integrasi Google Sheets

Masukkan URL Webhook Google Apps Script milik Anda di bawah ini agar nilai siswa dari semua Chromebook dapat **otomatis tersimpan secara real-time di Google Sheets Anda**.

Anda juga dapat langsung memasukkan URL ini ke variabel DEFAULT_WEBHOOK_URL di dalam kode HTML.

Panduan Singkat Pemasangan (Cuma 1 Menit!):

  1. Buka Google Sheets baru & beri judul (misal: Nilai Ulangan Informatika 9).
  2. Klik menu Ekstensi > Apps Script.
  3. Hapus semua kode lama, lalu tempel kode script di bawah ini:
function doPost(e) {
  try {
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    var data = JSON.parse(e.postData.contents);
    if (sheet.getLastRow() === 0) {
      sheet.appendRow(["Tanggal", "Nama Siswa", "Kelas", "Skor (0-100)", "Benar", "Salah", "Durasi Pengerjaan"]);
      sheet.getRange(1, 1, 1, 7).setFontWeight("bold").setBackground("#e2e8f0");
    }
    sheet.appendRow([
      new Date(),
      data.nama,
      data.kelas,
      data.skor,
      data.benar,
      data.salah,
      data.durasi
    ]);
    return ContentService.createTextOutput("Success").setMimeType(ContentService.MimeType.TEXT);
  } catch(err) {
    return ContentService.createTextOutput("Error: " + err.toString());
  }
}
  1. Klik tombol Terapkan (Deploy) > Penerapan Baru (New Deployment).
  2. Pilih Jenis: Aplikasi Web (Web App).
  3. Ubah Who has access (Siapa yang memiliki akses) menjadi: Anyone (Siapa Saja).
  4. Klik Terapkan, lalu salin URL Aplikasi Web dan tempel ke dalam file ini.
